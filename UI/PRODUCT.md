# LOBBOT

<!-- impeccable:product-schema 1 -->

## Platform
web

## Stack
Open decision: no production stack has been selected. This first identity exploration uses portable static HTML, CSS, JavaScript and editable SVG assets as a reversible implementation choice.

## Users
AI engineers and future developer users who need a smaller pretrained model specialized for a chosen capability. The project is being developed at a hackathon. The user confirmed the presentation should primarily address future developer users with more technical content.

## Product Purpose
An autonomous model-compression agent experiments on a large pretrained model while repeatedly evaluating a user-selected capability. It aims to produce a smaller specialized model requiring fewer computational resources.

## Positioning
Capability-guided reduction: modify or remove components, evaluate the target task, keep acceptable changes, restore damaging changes, repeat. The central analogy is awake brain surgery, where a function is tested continuously while an intervention is performed.

## Operating Context
Users provide a pretrained model, the capability to preserve, and optionally size, memory, latency or hardware constraints. Models may ultimately be intended for local or edge execution. The physical chatbot embodiment and future voice integration are later project phases.

## Capabilities and Constraints
The supplied workflow is a product concept, not a verified working backend in this repository. No compression results, hardware measurements, benchmark scores, availability, supported model list, customers or commercial claims have been supplied. Visual simulations must identify themselves as illustrative and must not imply an actual model has been compressed.

## Brand Commitments
The user confirmed the project name is LOBBOT. Create several logo proposals and a complete identity exploration before settling the final landing page and physical bot design. Use impeccable. The identity should feel precise, experimental, intelligent, technical, slightly provocative and memorable. Avoid generic purple/blue AI gradients, chatbot imagery, glowing robot brains, excessive sci-fi and generic neural-network logos. Explore surgical precision, scientific instruments, model architecture, subtraction, diagrams, laboratory equipment and industrial design.

The user subsequently selected logo M, "Sillon": an organic brain contour with an open incision. Preserve that geometry. The user asked for a relationship to lobotomy and less square forms, then requested color palettes shown in action. The final palette is still open.

The user requested a native iPhone UI in Xcode comparing A / Anatomie and B / Soufre. This prototype complements the web identity explorer. Both modes must use the same UI and preserve the selected Sillon logo; neither palette is final yet.

- Experimentation remains evaluative and reversible.
- Efficiency claims require measured evidence.
- Identity should be recognizable without the wordmark.
